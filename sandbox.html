What Makes Technology Useful?

A technical solution should do more than function correctly. It should also consider the people who use it, the environment in which it operates, and the potential risks associated with it.

  • Is the solution understandable to its users?
  • Can it adapt to different situations?
  • Has it been tested effectively?
  • Are security and accessibility considered?
  • Can the solution be improved over time?

AI & Security Thought Experiment

Imagine an organization uses an AI-powered application to help employees process sensitive information. The system is efficient, but employees begin entering information that should not be shared with an external AI service.

What should happen first?
Before improving the system's efficiency, I would identify the type of information being handled, determine the security and privacy risks, establish appropriate data-handling rules, and make sure users understand how the system should be used. Responsible technology requires balancing functionality with security and user awareness.
